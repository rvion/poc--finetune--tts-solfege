Comment ça marche

  1. Le micro est découpé en fenêtres de 1 s (pas de 250 ms).
  2. Chaque fenêtre → log-mel (features.js, miroir exact du Python).
  3. Un CNN (~150k params, model.onnx) prédit 8 classes : 7 notes + bruit.
  4. Les prédictions consécutives sont fusionnées, le bruit est jeté → suite de notes.

POC — rvion/poc--finetune--tts-solfege. Entraînement 100 % synthétique (TTS). Précision mesurée sur voix TTS tenues à l'écart.
